# НИРС. Проектирование СКС
*Кафедра ИУ-3. Бакалвариат. 3 семестр*

*2026-09-01*

**Группы:** ИУ3-31Б, ИУ3И-31Б, ИУ3-32Б, ИУ3И-32Б, ИУ3-33Б, ИУ3И-33Б

**Выдача задания**

На первой неделе семестра необходимо скачать [бланк задания](doc/zadanie_nirs.docx) в формате MS Word, **впечатать** в бланк личные данные, распечатать в двух экземлярах, подписать и передать преподавателю или секретарю кафедры.
Один экземпляр бланка задания, подписанный заведующим кафедрой и руководителем НИРС, следует получить обратно на второй неделе и сохранить для отчета.

**Консультации:** время консультаций будет дополнительно согласовано. (Предварительно: пятница, с 11:00 до 14:00, кафедра)
